# Student Management System

A console-based Student Management System developed using Python and MySQL.

## Technologies Used
- Python
- MySQL
- MySQL Connector/Python

## Features
- Add student records
- Display all student records
- Search students by roll number
- Update student marks
- Delete student records

## Database
- Database: student_database
- Table: student_data

## Installation

1. Install Python and MySQL.
2. Install required packages:

```bash
pip install mysql-connector-python python-dotenv
```

3. Create the database and table using MySQL.
4. Create a `.env` file in the project root and configure MYSQL_PASSWORD.
5. Run the application:

```bash
python python/std_system.py
```
